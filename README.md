# ZURIQON TECHNOLOGY GROUP (ZTG)

> **Technology. Innovation. Transformation.**
> *Building the Future Through Technology.*

A premium, modern corporate homepage and digital platform for **Zuriqon Technology Group (ZTG)** engineered with React, Vite, Tailwind CSS, Lucide icons, Three.js 3D WebGL visualizations, and Supabase PostgreSQL integration.

---

## 🎨 Visual Identity & Architecture

- **Primary Colors**: Deep Black (`#070B10`), Dark Navy (`#0B1420`), Electric Blue (`#19BFFF`), Cyan (`#51E5F5`), Muted Slate (`#A7B3C2`).
- **Typography**: Inter, Manrope, Space Grotesk.
- **Hero Visual**: Real-time interactive 3D WebGL Digital Globe with Fibonacci vertex distribution, glowing cyan/blue nodes, curved network arcs, orbiting data particles, and mouse-damped rotation.
- **Glassmorphism**: Translucent panels with subtle cyan/electric-blue borders and soft ambient blurs.
- **Accessibility**: Includes `prefers-reduced-motion` detection that gracefully stops 3D rotations and animations for sensitive users.

## 🚀 Quick Start

### 1. Run Development Server
From the workspace root:
```bash
npm run dev
```
Or inside `client/`:
```bash
cd client
npm run dev
```
The site will run on `http://localhost:5173`.

### 2. Build for Production
```bash
npm run build
```
Production assets are generated in `client/dist/` with optimized code splitting.

### 3. Run Backend (Optional)
```bash
npm run server
```
Runs the Express service on port `3000` (`/api/getdata`, `/api/post`, `/api/inquiries`).

## 🔌 Supabase PostgreSQL Integration

To link the Project Inquiry form to your Supabase PostgreSQL database:

1. Copy `.env.example` in `client/` to `client/.env`:
   ```bash
   cp client/.env.example client/.env
   ```
2. Populate your Supabase Project URL and Anon Public Key:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-public-key
   ```
3. Create the `inquiries` table in your Supabase SQL editor:
   ```sql
   create table inquiries (
     id bigint generated by default as identity primary key,
     full_name text not null,
     email text not null,
     phone text,
     requested_service text not null,
     project_description text not null,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );

   -- Enable Row Level Security (RLS)
   alter table inquiries enable row level security;

   -- Allow anonymous users to submit inquiries
   create policy "Enable insert for public" on inquiries
     for insert with check (true);
   ```

*Note: If no Supabase keys are configured, the frontend gracefully falls back to a simulated transmission with comprehensive validation and instant feedback.*
